API Test
1. JSON สำหรับส่งการแจ้งเตือนเหตุการณ์ (Trigger Alert)
Endpoint: POST /api/alert
Headers: Content-Type: application/json

JSON
{
  "node_id": "NODE_KPS_01",
  "event_type": "ต้นไม้ล้ม",
  "lat": 14.0245,
  "lng": 99.9732
}
node_id: รหัสประจำตัวของบอร์ด ESP32 เพื่อให้ระบุได้ว่ามาจากจุดไหน

event_type: ข้อความระบุประเภทเหตุการณ์ (ระบบจะใช้ข้อความนี้แสดงผลบนหน้าเว็บโดยตรง)

lat / lng: ค่าพิกัดจุดทศนิยมจากโมดูล GPS
